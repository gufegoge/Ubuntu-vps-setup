# Ubuntu VPS Setup

Настройка и администрирование VPS на базе Linux Ubuntu и изучение сетевых протоколов.

## Цель 

Получить практический опыт работы с Linux-сервером, настройки удалённого доступа и базовых мер безопасности, по сетевым протоколам.

## Техонлогии

- Ubuntu Linux
- SSH
- Firewall fail2ban
- Конфигурационные файлы Linux
- Системные службы
- Xray-core (для создания локальной сети с друзьями, данные передаются на личный сервер.)

## Что было сделано

- Установлены необходимые программы.
- Настроен удалённый доступ через SSH.
- Настроены правила firewall.
- Изучены и изменены конфигурации необходимых служб.
- Выполнены проверки работоспособности настроенной среды.

## Как проверялась работа

- Логирование.
- Доступность сети с устройств.

## С какими трудностями столкнулся

- Недоступность сервера (по вине хостера).
- Особенности работы системы безопасности ТСПУ (подстраиваться под стандарты системы безопасности своего соединения).
  
## Результат

Получен практический опыт настройки VPS, работы с конфигурациями Linux и базовыми инструментами защиты сервера и соединения между пользователями сети.

## Чему научился

- Работать с Linux-сервером через терминал (SSH, Termius).
- Настраивать SSH, firewall, fail2ban и xray-core.
- Разбираться в конфигурациях и системных службах.

## Примечание

Мой личный проект по изучению Linux системы и сетям, по мере изучения проект будет обновляться.
